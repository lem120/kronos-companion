# Kronos Companion 1.1.0

Stable release for Kronos 2017 v1.49 and Bitfocus Companion 5.1+.

## Highlights

- Stable macOS and Windows bridge workflow
- Dynamic timer names and countdown values
- Play / Pause / Reset controls
- Live/Broadcast button states
- Correct overtime formatting
- macOS/Windows database auto-discovery
- **Follow Kronos Order**
- Fixed ID legacy mode
- Backup and rollback installers
- Public installers apply a local delta patch instead of distributing a complete modified Kronos SWF
